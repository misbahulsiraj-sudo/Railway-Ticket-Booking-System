🚂 Railway Ticket Booking System

A simple and user-friendly Railway Ticket Booking System developed using Python. This project allows users to view available trains, book tickets, search bookings using PNR numbers, and cancel tickets through a menu-driven interface.

Features

- View available trains
- Book railway tickets
- Generate unique PNR numbers
- Search booking details using PNR
- Cancel booked tickets
- Automatic seat availability update
- Fare calculation
- Input validation
- Simple and clean console interface

Technologies Used

- Python
- Dictionaries
- Functions
- Loops & Conditional Statements
- Random Module

How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

python railway_booking.py

Project Purpose

This project was created to practice Python programming concepts such as functions, dictionaries, data handling, input validation, and basic application logic.
